## 产品目标

联网传感器终端（参考方案第 5 节）：按键控制模式、LED 显示状态、I2C 采样、
Wi-Fi 接入与上报、NVS 配置、诊断命令。AI 运行在电脑端，固件负责本地采集与控制。

## M1 范围：本地输入输出

| 功能 | 行为 |
| --- | --- |
| LED | GPIO8，低电平点亮。模式：慢闪（1000 ms 翻转）、快闪（200 ms）、常亮 |
| 按键 | BOOT/GPIO9，低电平按下。**短按 20–800 ms 切换模式**，每次按压只产生一次事件 |
| 去抖 | 10 ms 采样，连续 3 次（≥30 ms）稳定才确认状态变化 |
| 模式循环 | SLOW → FAST → SOLID → SLOW |
| 日志 | 启动输出模式/周期/引脚；按键按下、释放、有效短按、模式切换均输出；每 10 s 心跳（模式、空闲堆、最小空闲堆） |
| 错误处理 | 初始化失败中止启动（ESP_ERROR_CHECK）；过短（<20 ms）或过长（>800 ms）按压忽略并记录原因 |
| 启动约束 | GPIO8/GPIO9 为启动绑带引脚：LED 熄灭态为高；按住 BOOT 上电会进入下载模式，属预期 |
| 传感器框架 | M1 默认虚拟传感器（`CONFIG_APP_SENSOR_MOCK=y`），2 s 采样；读取失败计数并记录，不阻塞本地功能；真实 I2C 驱动待型号/引脚确认 |
